# 鴉羽邸（からすばてい） — 設計書

2D見下ろし型・探索脱出ホラー。TypeScript + Phaser 3 + Vite。外部素材なし（グラフィックはCanvas生成、音はWeb Audio合成）。

## 構成

```
src/
  main.ts              Phaser起動
  core/constants.ts    タイルサイズ・速度などの定数
  core/state.ts        ゲーム状態（フラグ・所持品・メモ）と進行修復
  core/save.ts         localStorage セーブ（チェックサム＋バックアップ）
  world/mapdata.ts     部屋・ドア・ポータル・家具・セーブ地点の定義
  world/grid.ts        タイルグリッド構築、衝突、視線(LOS)、A*経路探索
  gfx/pixel.ts         ピクセル描画ヘルパ
  gfx/textures.ts      全テクスチャのCanvas生成（床/壁/家具/人物/怪物）
  audio/audio.ts       Web Audio 合成エンジン（BGM・接近音・SE）
  ui/ui.ts             DOM UI（会話・選択肢・メニュー・HUD・タッチ操作）
  ui/puzzles.ts        謎解きパネル（金庫・本棚・肖像画・配電盤）
  game/GameScene.ts    メインシーン（描画・入力・照明・霧・進行）
  game/actors.ts       プレイヤー／NPC／移動と衝突
  game/monster.ts      怪物AI（徘徊・警戒・追跡・捜索・撤退）
  game/director.ts     出現スケジュールと環境演出
  game/story.ts        調べる処理・イベントシーン・テキスト
```

## マップ（1枚の連続グリッド＋階段ポータル）

1階：北廊下 / 南廊下を軸に、上段（寝室・子供部屋・浴室・キッチン）、
中段（図書室・リビング・食堂）、下段（書斎・玄関ホール・階段室）。
地下：地下室（柱が並ぶ大部屋）、地下倉庫、地下水路（脱出地点）。
隠し部屋：書斎の肖像画の裏から階段で。

ループ（逃走ルート）：寝室⇔子供部屋、北廊下⇔リビング⇔南廊下⇔食堂⇔北廊下、
玄関ホールの2つのドア、地下室の柱。

## 進行

1. 導入：玄関でサキとはぐれる（扉が閉まる）
2. 寝室で懐中電灯（電池切れ）＋キッチンで電池 → 照明強化
3. 寝室のクローゼットで針金ハンガー → 浴室の浴槽の栓を抜く【謎1】→ 図書室の鍵
4. 初遭遇イベント（北廊下）→ 以後、怪物が徘徊
5. 図書室：色の本棚【謎2】（子供部屋の絵本がヒント）→ 書斎の鍵
6. 書斎：金庫【謎3】（4部屋の肖像画の数字＋食堂の日記で順番）→ 地下室の鍵
7. 地下：配電盤【謎4】（ライツアウト）→ 電気復旧、シャッターが開きサキと再会 → 肖像画の切れ端
8. 書斎：肖像画の並べ替え【謎5】→ 隠し部屋 → 鉄格子の鍵 → 壁が崩れ最終追跡
9. 地下室を駆け抜け鉄格子を開け脱出 → エンディング

## 怪物AI

状態：`absent / wander(徘徊) / alert(警戒) / chase(追跡) / search(捜索) / leave(撤退)`
- 視覚：前方120°・9タイル、追跡中は全方位12タイル。壁・閉じたドアで遮断（LOS）
- 聴覚：ダッシュ足音（半径6）、ドア開閉（半径5）
- 経路：8方向A*（角抜け禁止）＋ポータル辺＋視線による経路平滑化
- 追跡中は見失っても1.5秒は実位置を追う（部屋をまたぐ追跡）→ 最終目撃地点 → 捜索
- 捜索：周辺の地点と隠れ場所を調べる。隠れる所を見られていたら高確率で発見
- 一定時間で撤退・消滅 → ディレクターがランダム間隔で再出現
- 公平性：出現はプレイヤーから経路14タイル以上・視線外。追跡開始直後は加速が緩やか。
  ダッシュ（スタミナ制）なら引き離せる速度設定。

## セーブ

localStorage `karasuba.save.v1`（本体）と `.bak`（1つ前）。JSONに FNV-1a チェックサム。
破損時はバックアップから復元。ロード時 `repairProgress()` で鍵の消失などを修復。
